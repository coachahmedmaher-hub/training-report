صانع تقارير العملاء

الصفحة دي ليك انت بس. الملف بيتقري على جهازك ومش بيتبعت لأي مكان.

افتح الملف في Excel واعمله Save الأول، عشان الأرقام تبقى محسوبة جواه.
نفس الكود = نفس الملف. لو عملت تقرير جديد بنفس الكود، هيستبدل القديم.

بعد ما الملف ينزل

  1. ادخل على الـrepository بتاعك في GitHub، وافتح فولدر reports.
  2. اضغط Add file ← Upload files، واسحب الملف اللي نزل، وبعدين Commit changes.
  3. استنى دقيقة أو اتنين، وابعت للعميل الكود ولينك الموقع.
