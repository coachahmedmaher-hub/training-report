# Client Reports — Coach Ahmed Maher

موقع تقارير العملاء. العميل بيكتب الكود بتاعه، فيظهر له تقريره.

## الملفات

| الملف | وظيفته |
|---|---|
| `index.html` | الصفحة اللي العميل بيفتحها |
| `admin.html` | صفحتك انت: بتعمل منها ملف التقرير لكل عميل |
| `assets/config.js` | اسمك، ورقم الواتساب، والإنستجرام، ولينك حجز الريكفري. ده الملف الوحيد اللي ممكن تعدّله |
| `assets/i18n.js` | الترجمات: عربي، إنجليزي، هندي، فلبيني، فرنساوي |
| `reports/` | ملفات تقارير العملاء، وكلها متشفرة |

## مرة واحدة: رفع الموقع على GitHub Pages

1. اعمل حساب على github.com لو مش عندك.
2. اعمل repository جديد: اضغط **New**، وسمّيه مثلًا `reports`، واختار **Public**، وبعدين **Create repository**.
3. في صفحة الـrepository، اضغط **uploading an existing file**. اسحب **كل الملفات والفولدرات** اللي في الـZIP، وبعدين **Commit changes**.
4. افتح **Settings ← Pages**. من **Branch** اختار `main`، وبعدين **Save**.
5. بعد دقيقة أو اتنين، اللينك هيظهر فوق، وشكله كده: `https://USERNAME.github.io/reports/`

## كل مرة تعمل تقرير لعميل

1. افتح ملف `Coach_Training_Load.xlsx` بتاع العميل في Excel، واعمله **Save**.
2. افتح `https://USERNAME.github.io/reports/admin.html`.
3. اختار الملف، ودوس **كود جديد**. ممكن تكتب ملاحظاتك لو حابب، وبعدين دوس **اعمل ملف التقرير**.
4. ملف `xxxx.json` هينزل عندك. ارفعه جوه فولدر `reports` في الـrepository: **Add file ← Upload files ← Commit**.
5. ابعت للعميل اللينك والكود.

- **تحديث تقرير:** اعمل نفس الخطوات بنفس الكود، وارفع الملف الجديد مكان القديم، لأن اسمه هيكون هو هو.
- **إلغاء تقرير:** امسح ملفه من فولدر `reports`.

## الحماية

- التقارير **متشفرة بالكود**. حتى لو حد فتح الـrepository، مش هيعرف يقرا أي تقرير من غير الكود بتاعه.
- الصفحة بتمنع كليك يمين والنسخ والطباعة، وعليها علامة مائية باسم العميل. بس محدش يقدر يمنع سكرين شوت 100%.
- استخدم الكود اللي بيطلع من زرار «كود جديد» (6 حروف/أرقام عشوائية بعد الاسم). ماتستخدمش أكواد سهلة زي `HANI1`.
